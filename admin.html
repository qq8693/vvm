导入 / 导出

网站读取的是 data/products.js，导出后用新文件覆盖它，再上传 GitHub。

导出（改完商品就做这一步）

导出的是整个网站的数据：店铺设置 + 分类 + 所有商品（图片已内嵌）。

下载得到的 products.js 直接覆盖网站 data/ 文件夹里的同名文件即可。

导入

换电脑了、或者想恢复之前的版本，可以导入已有的数据文件。

支持 products.js 和 products.json
导入会完全替换当前浏览器里的数据。建议先导出一次做备份。

重置

这两个操作不可撤销。

数据存在哪里？

这一条比较重要，建议看完。

你的商品数据保存在这个浏览器的本地存储里（关掉页面下次打开还在）。 但它不会自动同步到别的电脑或浏览器，也不能只靠它当备份。
所以：每次改完商品，都点一次「导出 products.js」，把文件保存好。

使用教程

零基础也能跑通，照着做就行。

一、网站是怎么跑起来的

不需要买服务器、不需要买域名。

整个网站就是一堆静态文件。你把它上传到 GitHub，GitHub 会免费帮你托管， 并给你一个像 https://你的用户名.github.io/仓库名/ 的网址。 别人打开这个网址就能看到你的商品，不花一分钱。

二、第一次发布到 GitHub（大概 10 分钟）

  1. 打开 github.com，注册一个账号（免费），记住用户名。
  2. 登录后点右上角 + → New repository。
  3. 仓库名填一个英文名，比如 myshop；可见性选 Public；点 Create repository。
  4. 进入仓库后点 Add file → Upload files，把整个网站文件夹里的内容拖进去：
    index.html、admin.html、assets 文件夹、data 文件夹、images 文件夹。
    （README.md 也可以一起传，方便自己以后看。）
  5. 页面拉到底点绿色的 Commit changes，等它上传完。
  6. 在这个仓库里点 Settings → 左侧菜单找到 Pages。
  7. Source 选 Deploy from a branch；Branch 选 main，目录选 / (root)；点 Save。
  8. 等 1～3 分钟，刷新这个页面，顶部会出现你的网址，形如
    https://你的用户名.github.io/myshop/
    把这个网址发给客户，就能看你的商品了。
第一次可能需要等几分钟才生效；如果打开是 404，先等 2 分钟再刷新试试。

三、以后怎么更新商品

  1. 双击打开 admin.html（就是你现在这个页面）。
  2. 在「商品管理」里增删改。想先看看效果，点左下角 在浏览器里预览网站。
  3. 回到左侧点 导出 / 导出 里的 下载 products.js。
  4. 登录 GitHub，进入你的仓库，点开 data 文件夹，再点 products.js。
  5. 点右上角的 铅笔图标（Edit）→ 或者直接点 Upload files 把这个新文件重新传一次覆盖。
  6. 拉到底点 Commit changes。等 1～2 分钟，刷新你的网站，新商品就出现了。
最省事的做法：在仓库首页点 Add file → Upload files， 把新导出的 products.js（以及新增的图片）拖进去覆盖，然后 Commit changes。 不用一层层点文件夹。

四、关于图片

这是最容易踩坑的地方，看完能省很多事。

在这个工具里上传图片后，图片会被自动压缩并直接放进 products.js 里。 好处是你只要传一个文件就完事，不用管图片文件夹。
建议：单张图压缩到最长边 1200px、质量 0.8 左右。 商品 30 件以内完全没问题。
如果商品很多（比如 100 件以上），products.js 会变得很大、打开变慢。 这时可以把图片改成放在 images/ 文件夹里，用相对路径引用， 例如在「图片」里粘贴 images/coat-01.jpg，然后把图片文件一起传到 GitHub 的 images 文件夹。

五、中英文双语怎么用

网站右上角有个「English / 中文」按钮，客户可以随时切换。你只需要把两种语言的文字都填上。

1. 语言切换按钮
在「店铺设置 → 语言与货币」里可以关掉它。默认显示哪种语言也在那里选。 客户手动切过之后，网站会记住他的选择。
2. 英文字段可以慢慢补
所有英文栏（Product name、Description、Size labels、Tags、参数英文列、分类的 Name English…） 留空时，英文界面会自动显示中文，网站不会出现空白。所以你可以先上线，再一件件补英文。
3. 哪些一定要填？
外贸站最该优先填的是：商品英文名、英文描述、分类英文名、店铺英文名，以及联系方式里的 WhatsApp / 邮箱。 商品列表里显示「缺英文」黄标的，就是还没补英文名的商品。
4. 英文价格
英文界面的价格 = 中文价格 × 「语言与货币」里填的数字，货币符号用你填的那个。 填 1 表示不换算。汇率不会自动更新，请按你的实际报价填写并定期检查。 填 0 或留空会被当成 1。
5. 联系方式会自动变成英文标签
微信号显示为 WeChat、电话显示为 Phone、邮箱显示为 Email，WhatsApp 直接点一下就能打开聊天窗口，客户不用复制粘贴。

六、常见问题

Q：双击 index.html 打开，商品怎么不显示？
A：应该能显示的。如果没显示，检查 data/products.js 是否和 index.html 在同一个项目文件夹里（位置不能挪）。
Q：改了商品，网站没变化？
A：① 确认已经 Commit；② 等 1～2 分钟；③ 手机上按 Ctrl+F5 / 清理缓存刷新。
Q：能做付款下单吗？
A：纯静态网站不能收款。常见做法是：客户看中后加你微信/打电话，你手动收款发货。 这也是这个网站的「联系店主」按钮的用途。
Q：以后想用自己的域名？
A：买个域名（一年几十块），在 GitHub Pages 设置里填上，再在域名商那里加一条解析就行。这个以后想弄再问我。
Q：数据丢了怎么办？
A：用「导入」功能，选择你之前导出的 products.js 就能恢复。
